# 의정온 · 의정자료 관리

의원과 보좌진이 의정자료, 업무, 일정과 팀 활동을 한 화면에서 함께 관리하는 반응형 협업 대시보드입니다. 별도 프레임워크 없이 표준 HTML·CSS·JavaScript로 구성했습니다.

## 실행 방법

```bash
npm run dev
```

터미널에 표시되는 주소(기본값 `http://localhost:5173`)를 브라우저에서 여세요.

## 주요 기능

- 의정자료 분류 필터와 즐겨찾기
- 새 자료 등록 및 브라우저 저장소 보존
- 오늘의 업무 완료 체크
- 다가오는 일정 및 팀 활동 피드
- 데스크톱·모바일 반응형 화면

샘플 자료, 일정, 업무와 구성원은 `src/data.js`에서 수정할 수 있습니다.

## 배포 전 확인

```bash
npm test
npm run build
```

생성된 `dist` 폴더를 Netlify, Vercel, GitHub Pages 같은 정적 호스팅 서비스에 배포할 수 있습니다.
